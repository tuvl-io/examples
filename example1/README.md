# example1

> Built with [tuvl](https://tuvl.io) — compose AI-powered backend workflows
> using YAML, Python nodes, LLM calls, and database operations.

## Quick Start

```bash
# 1. Install dependencies
uv sync

# 2. Copy the secrets template and fill in your values
cp .env.example .env

# 3. Start the development server
tuvl dev --project-dir .
```

The engine starts at **http://localhost:8885** and the
[Tuvl Insight](https://tuvl.io) developer portal is available at
**http://localhost:8885/insight**.

## Project structure

```
example1/
├── pyproject.toml       # Python project & dependencies
├── .env                 # secrets (git-ignored)
├── .env.example         # safe-to-commit template
├── .gitignore
├── models/              # ModelDefinition YAMLs — database schema
├── workflows/           # Workflow YAMLs — HTTP-triggered pipelines
├── datasources/         # DataSource / RedisConfig YAMLs
├── llms/                # AgentModel YAMLs — LLM model configs
├── federation/          # FederationProvider YAMLs — OAuth providers
└── nodes/               # Python node implementations (@node decorator)
```

> **`--sample` flag** adds `.tuvl/telemetry.yaml`, `tests/workflows/`, and a ready-to-run
> recruitment screening workflow covering every step kind.

## Common tasks

| Task | Command |
|------|---------|
| Start dev server | `tuvl dev --project-dir .` |
| Validate all files | `tuvl validate --project-dir .` |
| Package for production | `tuvl ship` — container image + Helm chart |
| Add a Python dep | `uv add <package>` |
| Scaffold a new node | Create `nodes/<name>.py`, use `@node("<name>")` |
| Add a workflow | Create `workflows/<name>.yaml` with `kind: Workflow` |
