# Citation style

Apply this when preparing the sources for your final answer.

- Cite every source you relied on in a numbered list.
- Use the format: `[n] title — url`
  - Example: `[1] RFC 8259: The JSON Data Interchange Format — https://www.rfc-editor.org/rfc/rfc8259`
- Number citations in the order you first used them.
- Each source in your `result` must carry `url`, `title`, and `takeaway`, so the
  downstream composer can render the numbered list and ground each claim.
- Do not cite a page you did not fetch and summarize.
