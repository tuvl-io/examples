# Security Basics

Every employee is responsible for protecting company data.

- **Passwords:** use the company password manager; minimum length is **16
  characters**. Never reuse a personal password.
- **MFA:** multi-factor authentication is mandatory on all company accounts.
- **Phishing:** report suspicious emails with the "Report Phish" button. Never
  enter your credentials after following a link from an unsolicited email.

Lost or stolen devices must be reported to the security team within **1 hour**.
